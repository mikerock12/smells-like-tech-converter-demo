# Amostras do Office 97–2003

Arquivos de teste do Apache POI (licença Apache 2.0), baixados de
https://github.com/apache/poi/tree/trunk/test-data:

- `SampleDoc.doc` — test-data/document/SampleDoc.doc
- `SampleSS.xls` — test-data/spreadsheet/SampleSS.xls
- `SampleShow.ppt` — test-data/slideshow/SampleShow.ppt

Usados por `DocumentosTest` para conferir os leitores de .doc, .xls e .ppt.
