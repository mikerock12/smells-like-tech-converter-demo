# Referências externas em avaliação

A [auditoria de modelos](../auditoria-modelos.md) registra os repositórios oficiais, as fichas de pesos e as dúvidas sobre os dados. CodeFormer e BRIA RMBG 2.0 constam como referências com restrições comerciais. A receita do ampliador próprio gera os exemplos por procedimento e treina a partir desses pixels.
