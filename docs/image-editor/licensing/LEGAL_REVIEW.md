# Decisões de distribuição do editor de imagem

Em 21/11/2026, o registro do editor contém um modelo de bancada pendente e zero pesos aprovados para distribuição. A aprovação concedida anteriormente para os modelos de áudio refere-se à separação musical. A auditoria específica de imagem está em [auditoria-modelos.md](../auditoria-modelos.md).

Pareceres futuros em `approvals/` identificam a pessoa responsável, a data e o registro integral aprovado, incluindo a origem e o hash dos pesos. O campo de aprovação permanece reservado para decisões efetivas do titular ou responsável designado.
